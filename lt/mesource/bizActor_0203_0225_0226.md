# bizActor Definition — GMES_IMES_0203 / GMES_IMES_0225 / GMES_IMES_0226

All bizIDs used by the three screens (including their popup pages), extracted from the `.aspx` sources in this folder.

Two calling styles appear in the code:

| Style | How the bizID is passed | Service endpoint |
|---|---|---|
| `param.bizID = "..."` + `sendRequestMethod(...)` / `UCRealgrid.CallRequest(...)` | POST body, with `inTableNames` / `outTableNames` | page WebMethod (`GetData`, `GetDataSet`, `GetDataSetting`, `GetDataByDic`, `ExecuteData`) or `/GMES_COM/Service/CallBizJson.aspx/GetBizJsonByDictionary` |
| `sp_name=...` in a URL | query string (combobox `url:`) | `../common/xml/CallBizJson.aspx` |

Legend — **Type**: `BR_` = Business Rule, `DA_` = Data Access. **CUD/R**: R = read/select, X = execute (insert/update/delete).
